# 20단 구구단 프로그램 (C++)

## 📌 개요
C++로 작성된 1단부터 20단까지의 구구단 출력 프로그램입니다.
객체지향 프로그래밍 기법을 활용하여 구현되었으며, 다양한 출력 형식을 지원합니다.

## 🚀 주요 기능

### 1. 전체 구구단 출력 (세로)
- 1단부터 20단까지 순차적으로 출력
- 각 단마다 1×n부터 20×n까지 계산

### 2. 구구단 테이블 출력 (가로)
- 한 줄에 여러 단을 동시에 표시
- 테이블 형식으로 가독성 향상

### 3. 특정 단 선택 출력
- 사용자가 원하는 특정 단만 출력

### 4. 특정 배수 찾기
- 입력한 숫자의 배수를 구구단에서 찾아 출력

## 📦 컴파일 및 실행

### 방법 1: g++ 직접 컴파일
```bash

g++ -std=c++11 -o gugudan20 gugudan.cpp

# 실행
./gugudan20
```

### 방법 2: CMake 사용
```bash
# 빌드 디렉토리 생성
mkdir build
cd build

# CMake 구성
cmake ..

# 컴파일
cmake --build .

# 실행
./gugudan20
```

### Windows에서 실행
```cmd

# 실행
```


### 예제 출력

#### 특정 단 출력 (예: 7단)
```
========== 7단 ==========
 7 x  1 =   7
 7 x  2 =  14
 7 x  3 =  21
...
 7 x 20 = 140
```

#### 테이블 형식 출력
```
   [ 1단]      [ 2단]      [ 3단]      [ 4단]      [ 5단]   
-------------------------------------------------------------
```

## 🏗️ 코드 구조

```cpp

private:
    int maxDan;  // 최대 단 수 (20)

    void printAll();                 // 전체 출력

```
